# ENAMED 2025 institutional audit — supplementary evaluation

This review package contains real course-level results, executable evaluation scripts and a review dashboard. Author names, local author paths and identifying repository links are omitted. Public INEP course codes are retained in the underlying data to support exact reproduction; the displayed examples use Program A/B. This masks authorship cues and does not make public institutions unidentifiable or guarantee data anonymity.

## Contents and provenance

- `data/course_payloads.json`: 350 original course-level payloads, reproduced exactly from the supplied raw microdata during revision.
- `data/full_fit.json`: regenerated full-data model outputs used by the dashboard. These are in-sample outputs, not cross-validation predictions.
- `results/predictive_audit.json` and `oof_predictions.csv`: revised held-out predictive evaluation, with feature selection and imputation fitted inside training folds.
- `results/fidelity_report_real.json`: supplied offline deterministic-versus-fabricated-baseline report; aggregate totals reproduced during revision.
- `results/fidelity_report_gemini.json`: supplied historical live-model report. Its numeric totals were checked; model responses were not archived in that report and could not be independently rescored semantically.
- `code/`: portable reproduction scripts and executable review view. The review view uses real payloads and deterministic explanations; it is not a screenshot of a newly executed Gemini response.
- `figures/`: figures used in the revised paper. No statistical or dashboard values were generated by an image model.

## Reproduce

Tested analytical runtime: Python 3.12.14. Create a virtual environment, then run commands from this directory:

```sh
python -m pip install -r requirements.txt
python code/audit_predictive.py --data /path/to/microdados_enade_2025_arq3.txt --outdir reproduced
python code/rebuild_payloads.py --data /path/to/microdados_enade_2025_arq3.txt --out reproduced/course_payloads.json
python code/fidelity_check.py --payloads data/course_payloads.json --grounded local --baseline naive --out reproduced/fidelity.json
python -m streamlit run code/dashboard.py
```

Obtain the public ENAMED 2025 microdata from INEP: https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados . Extract the ENADE file named above. Raw student-level rows are not redistributed here. Exact input SHA-256: `eb3e2d6f7ce58f8e5f5f04308923eeee349bcfa6eb389562f25a05852c953b79`.

Predictive check: 350 programs, median 65.18055961426066, 175 programs per class. Mean five-fold accuracy: majority .460, DT .654, GNB .749, LR .760, RF .743. RF macro-F1 .742. Settings inherited from earlier artifact development were not retuned; this does not remove possible prior model-development bias on the same cohort.

Offline fidelity: 3186/3186 grounded numbers; fabricated baseline 758/2100. Historical live experiment: grounded 494/503 and open 294/357; fully grounded courses 51/60 and 33/60. The first 60 payloads in file order were used, not a random sample. The checker measures numeric matching, not semantic truth. The offline baseline is deliberately fabricated and must not be described as a live LLM result. The open and grounded prompts differ in more than grounding alone.

## Optional live experiment

Install `google-genai` separately, set `GEMINI_API_KEY` in the environment, then run `python code/run_gemini_fidelity_local.py --payloads data/course_payloads.json --n 60 --out reproduced/new_live_report.json`. This makes external paid model calls. Model availability and generated outputs may change; a new run need not reproduce the historical report. Preserve the provided report separately. No API credentials are included. The supplied historical script does not preserve full responses, which limits retrospective checking.
